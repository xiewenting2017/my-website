# 组件变体规范

与 [SKILL.md](SKILL.md) 色板、间距一致。实现时优先 CSS 变量。

---

## 1. CategoryRowCard（消息分类行卡）

```
[48×48 渐变 r12–16]  标题 16/500
                     摘要 13 次要色 单行省略
```

- 白底 r16，pad 16，margin 水平 20、下 20（对齐页边距/模块间距）
- 图标与文字 gap 12

---

## 2. AppGridItem（应用宫格项）

- 布局：父级 **4 列**，项横向均分；图标与标签纵向居中
- 容器：约 **52×52**，`border-radius: 16px`，软渐变底，白字形 ~24
- 标签：12px / 400，`#323233`，上间距 8px，最多两行或单行省略
- **角标（自定义常用应用）**：右上外叠，直径 ~16px，`rgba(0,0,0,0.35)` 底 + 白 ±；`−`=已选可移除，`+`=未添加可加入

---

## 3. HeroBanner（工作台头图）

- 外卡：白底或直接圆角 16，左右边距 20（`--space-page`）
- 内区：浅蓝渐变（如 `#E3F0FF` → `#F7FBFF`），高约 120–140
- 左：主文案 16–18/600 主色或深色 + 次行 12–13 次要色
- 右：扁平插画（人物/云），勿遮挡文字
- 底中：指示点，激活=`#3A8EF5` 宽条/胶囊，未激活=`#C8C9CC` 圆点
- 与下一模块间距 `20px`

---

## 4. SectionHeader（区块标题）

- 左：标题 16–18/600；可前置 18–20 语义小图标（主色）
- 右：设置齿轮 / 更多 / 折叠 `^`，色 `#969799`
- 标题与内容间距 12–16；左右边距 20

---

## 5. SegmentTabs（分段文字 Tab）

- 横排文字：财务 / 行政 / …；右侧可固定汉堡图标
- 激活：`#3A8EF5` + 字重 600；未激活：`#969799` 或 `#666`
- 可无下划线；若需要，下划线 2px 主色、宽约文字宽
- 与下方宫格同属一块内容，切换只换宫格数据

---

## 6. SoftPrimaryButton（浅主色按钮）

- 高 40–44，宽可满卡内容区，`border-radius: 8–12px`
- 背景 `#E8F3FF`，文字 `#3A8EF5` 15–16/500
- 用于「去打卡」等次主操作；真正提交用实心主色按钮

---

## 7. StatusPill（状态胶囊）

- pad 水平 8、垂直 2–4，圆角满高
- 例：正常 → 底 `#E8F3FF` 字 `#3A8EF5`；未打卡 → 底 `#F2F3F5` 字 `#969799`；成功 → 浅绿底+`#52C41A`

---

## 8. MetricSplitCard（指标拆分卡）

- 白卡 r16 pad 16
- **合同管理**：左「今日到期」大数字主色 + 说明；右上下两小块「7日内/30日内」+ 小圆角标计数
- **智能巡检**：两枚并排大数字摘要；可右下角低透明装饰图标
- 数字 22–28/600 主色；说明 12–13 次要色

---

## 9. TodoRow（待办行）

- 左：28–32 圆角方标（语义色底或渐变）+ 白小图标
- 中：标题 15/500；下行项目/截止 12 次要色
- 行间分割 `#EBEDF0` 或 12px 间距
- 整行可点，右可不放 chevron（列表内）或放 chevron（入口型）

---

## 10. FileGrid（协作文件）

- **3 列**；项为文件类型色标（Word 蓝 / Excel 绿 / PPT 橙 / PDF 红）+ 文件名 12 省略
- 浅灰底小卡可选；间距约 12

---

## 11. QuickActionGlass（审批顶栏快捷）

- 一行 4 等分；上图标下 12px 标签
- 图标区：约 48 圆或圆角方，半透明蓝/主色软底，白或浅白字形（可轻微玻璃感，**禁止**重 blur 整页）
- 角标：红底白字数字，右上叠放

---

## 12. CollapseGroup（可折叠分组）

- 头：左「分组名称」16/600 · 右折叠箭头
- 展开：下挂 4 列 AppGridItem，组内 pad 下 16
- 组间：1px `#EBEDF0` 或 16 留白

---

## 13. FormField（表单字段）

```
标签 14 主色文字  [*]可选红星
值 / 占位 15–16
──────────────── 1px #EBEDF0
```

- 标签与值纵向排列，字段垂直 pad 约 12–14
- 占位：`请选择` / `请输入` → `#C8C9CC`
- 选择类右侧可加灰 chevron
- 人员类字段占位「请选择人员」，点击打开 **PersonPicker**

---

## 14. ApprovalTimeline（审批流程）

**区头**：背景 `#F0F7FF`，左侧 3–4px 竖条 `#3A8EF5`，文案「审批流程」15/600

**节点**：
| 角色例 | 圆标色 |
|--------|--------|
| 发起人 | `#52C41A` |
| 部门领导 | `#3A8EF5` |
| 行政副总等 | `#13C2C2` |
| 抄送人 | `#FA8C16` |

- 圆标直径 ~32，白线性图标；竖线 1px `#E5E5E5` 居中串联
- 标题行：角色名 15/600 + 旁注 12 次要色（如「2人依次审批」「2人或签」「2人会签」）
- **人名 Chip**：高 ~28，圆角满高，pad 水平 10–12；默认底 `#E6F4FF` 字 `#3A8EF5`；特殊角色可用紫系标签
- **逻辑符**（Chip 之间）：`>` 依次 · `/` 或签 · `+` 会签/并联
- **添加**：虚线边框 Chip「+添加审批人」，字次要色或主色；点击打开 **PersonPicker**

---

## 15. SearchBar

- 白底，高 ~36–40，`border-radius: 8–12px`，左右边距 20
- 左 16–18 灰放大镜 + 占位 14 `#C8C9CC`

---

## 16. RecentChip（最近搜索）

- 白底小卡，r8–12，pad 8–12，字 13 `#323233`
- Chip 间距 8–10；可横向换行

---

## 17. ListNavRow（结果/入口行）

- 白卡 r16 pad 16：左 40–48 色标图标 · 中标题 · 右 `#C8C9CC` chevron
- 或通栏白底+底分割，与表单列表风格统一时可二选一，同页勿混用

---

## 18. ReorderCard（排序行卡）

| 状态 | 背景 | 边框 | 文字/柄 |
|------|------|------|---------|
| 默认 | `#FFFFFF` | 无 | `#323233` / 柄 `#C8C9CC` |
| 选中/拖拽 | `#EBF4FF` | `1px solid #3A8EF5` | 均 `#3A8EF5` |

- 高约 56–64，r16，水平 margin 20，垂直间距 20（模块间距）
- 右：2×3 点阵拖拽柄，热区 ≥ 44

---

## 19. AttendanceBlock（考勤块，工作台内）

- 白卡内：定位/标题行 → 双列「上班/下班」时间大号字 → StatusPill → SoftPrimaryButton「去打卡」
- 未打卡时间可用 `--:--` + 次要色

---

## 20. InspectionLinks（巡检入口行）

- Metric 下方：若干行「已完成 / 待完成 / …」+ 右 chevron，行高 ≥ 44，分割线淡

---

## 21. PersonPicker（人员选择）

按上传稿：白底圆角面板 + 顶栏取消 + **居中**搜索 + 字母分组列表 + 右侧字母索引。用于审批人、抄送人、选人表单等。

```
┌─ 白面板 r16 · 轻阴影 ─────────────────┐
│ 取消（左上，次要灰）                    │
│  [🔍 请输入人名搜索]  ← 内容水平居中   │
│ ┌A──────────────────────────────────┐ │  ← 字母区头浅底
│ │ (张) 张三     ← 行选中浅蓝通栏      │ │
│ │ (李) 李四                            │A│
│ ├B──────────────────────────────────┤ │B│ 右侧索引
│ │ (王) 王五                            │C│
│ ├I──────────────────────────────────┤ │…│
│ │ (赵) 赵六                            │ │
└───────────────────────────────────────┘
```

### 壳层

| 属性 | 规格 |
|------|------|
| 容器 | 白底 `#FFFFFF`，圆角 `16px`，轻阴影 `0 1px 4px rgba(0,0,0,0.04)`（可略强） |
| 页边距 | 相对页面左右/上下遵循 **20px**；全屏弹出时可顶满宽，内边距仍 20 |
| 顶栏 | 左「取消」14–15 / `#969799`；可无中标题；无底栏时点行即选中返回 |
| 无底栏确认 | 单选：点行即选中并关闭；多选：底栏「确定」主色按钮 + 已选数 |

### 搜索（本组件内，异于全局 SearchBar）

- 高 ~36–40，圆角满高或 `8–12px`，底 `#F2F3F5` / `#F7F8FA`（浅灰，非白描边框）
- **放大镜 + 占位「请输入人名搜索」水平居中**（稿面特征；聚焦后可改为左对齐输入）
- 占位色 `#C8C9CC`；字 14
- 与下方列表间距约 12–16

### 字母区头

- 通栏浅底（近 `#F0F2F5` / `#F5F7FA`），高约 28–32
- 左对齐字母 13–14 / 500，色 `#969799` 或略深
- 按姓名拼音首字母分组；无数据字母不展示区头

### 人员行 PersonRow

```
[圆头像 40]  姓名 15–16/400  #323233
```

- 行高约 56–64；左右 pad 与页边距对齐（约 20）；头像与姓名 gap 12
- **默认**：白底；**无**行间分割线（靠区头与留白分层）
- **选中/按压**：整行通栏底 `#E8F3FF` 或 `#EBF4FF`（与 ReorderCard 选中一致）
- 多选时可在行右加主色勾选，仍保留浅蓝底

### 字头像 AvatarInitial

- 直径 **40**（可 36–44），正圆
- 内容：姓名**首字**，白或同色相深字均可；稿面为**浅色底 + 同色相深字**
- 色板轮换（禁止整页同一色）：

| 序 | 底 | 字 |
|----|----|----|
| 1 | `#E8F3FF` | `#3A8EF5` |
| 2 | `#E8F8EF` | `#52C41A` |
| 3 | `#FFF7E6` | `#FA8C16` |
| 4 | `#F3E8FF` | `#8B5CF6` |
| 5 | `#E6FFFB` | `#13C2C2` |

有真实头像 URL 时优先图，失败回退字头像。

### 右侧字母索引 IndexRail

- 贴列表右缘垂直排列 `A–Z`（+ 可选 `#`）
- 字 10–11，色 `#969799`；触控热区加宽（勿小于约 16 宽）
- 滑动/点按跳到对应区头；当前段可主色高亮
- 列表右侧预留约 16–20，避免姓名被挡

### 状态

- 搜索无结果：列表区居中次要色「无匹配人员」
- 空通讯录：Empty 文案，勿大插画
- 与 ApprovalTimeline「+添加审批人」、FormField「请选择人员」联动：点开本面板

| 页面 | 常用变体 |

| 消息 | CategoryRowCard |
| 工作台 | HeroBanner, AppGridItem, SegmentTabs, AttendanceBlock, FileGrid, MetricSplitCard, TodoRow, InspectionLinks |
| 发起审批 | QuickActionGlass, CollapseGroup, AppGridItem |
| 请假申请 | FormField, ApprovalTimeline, **PersonPicker** |
| 选人/抄送 | **PersonPicker** |
| 搜索 | SearchBar, RecentChip, ListNavRow |
| 分组排序 | ReorderCard |
| 常用应用 | AppGridItem(±) |
